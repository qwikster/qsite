Simple SvelteKit indie web site to show people who I am and what I do! Currently selfhosted on a rpi5 via Caddy. You're welcome to reuse assets for your own page!

### Running a dev server:
```sh
git clone https://github.com/qwikster/qsite && cd qsite
npm run dev
# visit http://localhost:5173
```

### If you'd like to host this yourself:
You'll probably want to use your own workflow. Example setup using Caddy:
```sh
sudo mkdir -p /srv/web && cd /srv/ # or wherever you prefer!
sudo chown -R $USER: . && cd web
git clone https://github.com/qwikster/qsite && cd qsite
npm run build
```
And add the website to your `/etc/caddy/Caddyfile`:

```caddyfile
  @root host subdomain.example.com # change this!
  handle @root {
    root * /srv/web/qsite/build
    try_files {path} /200.html
    file_server
  }
```

finally, `caddy reload`
